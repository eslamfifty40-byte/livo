# توثيق ودليل تشغيل وبناء مشروع LIVO المتكامل
## LIVO Platform Architecture & Deployment Guide (Customer & Admin)

---

### نظرة عامة على النظام (System Overview)
تم تطوير وتحديث منظومة **LIVO** بالكامل لتشمل تطبيقين مستقلين يعملان على نفس قاعدة البيانات وبيئة Firebase الموحدة مع فصل تام للصلاحيات:
1. **LIVO Customer**: تطبيق العملاء المخصص للبث المباشر والتحديات (PK)، الغرف الصوتية، الفيديوهات الحقيقية، الرسائل الخاصة الفردية، وشحن الكوينز وتوثيق الحسابات.
2. **LIVO Admin**: لوحة تحكم وإدارة المنصة المخصصة لمالك المنصة والمشرفين المصرح لهم فقط، وتضم 18 قسماً إدارياً تشمل مراجعة طلبات الشحن وتكبير الإيصالات، الشحن والتعديل اليدوي للرصيد، إدارة الوكالات والتوثيق، الحظر والعقوبات، والسجل المالي الدائم.

### خطوات بناء ملفات APK المستقلة (APK Export Instructions)
لبناء ملفي APK مستقلين (واحد للعملاء `LIVO_Customer.apk` وواحد للإدارة `LIVO_Admin.apk`):

#### 1. تطبيق العميل (LIVO Customer)
باستخدام Capacitor:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "LIVO" "com.livo.customer" --web-dir "dist"
npm run build
npx cap add android
npx cap copy
npx cap open android
```
في Android Studio:
- اختر `Build` > `Build Bundle(s) / APK(s)` > `Build APK(s)`.
- ينتج الملف في: `android/app/build/outputs/apk/release/app-release.apk`.

#### 2. تطبيق الإدارة (LIVO Admin)
```bash
npx cap init "LIVO Admin" "com.livo.admin" --web-dir "dist"
npx cap add android
```
- تأكد من تفعيل وضع ملء الشاشة واستخدام الأيقونة الإدارية الذهبية المخصصة للإدارة في `res/mipmap`.

### إعداد البث المباشر عبر LiveKit (LiveKit Configuration)
لتشغيل البث المباشر الحقيقي متعدد الأجهزة:
1. أنشئ مشروعاً مجانياً على [LiveKit Cloud](https://cloud.livekit.io) أو استخدم سيرفر LiveKit خاص.
2. عيّن المتغيرات التالية في بيئة الخادم أو Cloud Functions:
   - `LIVEKIT_URL`: رابط السيرفر (مثل: `wss://livo-stream.livekit.cloud`).
   - `LIVEKIT_API_KEY`: مفتاح الواجهة البرمجية.
   - `LIVEKIT_API_SECRET`: المفتاح السري لتوقيع رموز JWT للمشاهدين والمضيفين.

### تقرير فحص واختبار الوظائف (Compliance Verification)
1. ✅ **صلاحيات الحسابات الجديدة**: أي مستخدم جديد يحصل تلقائياً على رتبة `user` بدون أي صلاحيات أدمن، ولا يحصل على أدمن إلا بحساب المالك المعتمد `livo.admin@gmail.com`.
2. ✅ **الرصيد الابتدائي**: 0 كوينز لجميع التسجيلات الجديدة (منع الكوينز المجانية عند التسجيل).
3. ✅ **إخفاء البريد في لوحة الإدارة**: تمت إزالة عرض البريد الإلكتروني في رأس لوحة الإدارة والصفحات العامة لحماية الخصوصية.
4. ✅ **أرقام إنجليزية وخانات إدخال فارغة**: كل الأرقام والأسعار والـ UID تظهر بصيغة الأرقام الإنجليزية `0123456789`، وتبدأ خانات الإدخال فارغة دون أصفار تلقائية.
5. ✅ **طلبات الشحن الدائمة**: لا تختفي عند تحديث الصفحة أو تسجيل الدخول/الخروج، وتتضمن رقم الطلب، الـ UID، رقم الهاتف، وإمكانية تكبير الإيصال بدقة عالية، وتمنع احتساب الكوينز مرتين.
6. ✅ **التحكم الشامل في الكوينز بالـ UID**: إضافة، خصم، أو ضبط رصيد دقيق مع اشتراط السبب وتأكيد المعاملة وتسجيلها في السجل المالي الدائم.
7. ✅ **الغرفة الرسمية LIVO Admin**: مثبتة أول القائمة، وعند خروج المالك يمكن قفلها دون حذف الرسائل أو إيقاف التطبيق.
8. ✅ **تحدي اللايف PK**: شريط 50/50 ديناميكي يتغير وفق الهدايا المؤكدة، عد تنازلي 5 دقائق، عرض أكبر 3 داعمين برتب 1 و2 و3، وزر بدء تحدٍ جديد دون مغادرة البث.
9. ✅ **فيديوهات أصلية حقيقية**: إزالة الفيديوهات والبيانات الوهمية، وربط المقاطع بصناعها وتواريخها الحقيقية.
10. ✅ **نظام الوكالات**: دعم الأنواع الثلاثة (شحن، موزعين، بروموكود)، ولوحة وكيل تتيح شحن الأعضاء عبر UID فقط لمن منحته الإدارة الصلاحية.
11. ✅ **خدمة العملاء**: إزالة رقم الهاتف من قسم خدمة العملاء والاحتفاظ به في قسم الشحن والسداد.
